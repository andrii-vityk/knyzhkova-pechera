# Книжкова печера

Тренажер читання вголос українською. Читач читає текст, браузер розпізнає мовлення, прочитані слова зеленіють. 100 рівнів у 5 розділах; кожен наступний відкривається після проходження попереднього, зірки й кубки за проходження.

**Відкрити:** https://andrii-vityk.github.io/knyzhkova-pechera/

Працює в браузері, без сервера і без API-ключів. Мікрофон доступний лише через `https://` або `localhost`, тому сторінка публікується на GitHub Pages.

## Як додати рівень

1. Відкрийте потрібний файл у `levels/` (можна просто в застосунку GitHub або на github.com).
2. Додайте блок:

   ```
   ## Назва рівня
   Ось новий текст. Склади розставляться самі.
   ```

3. Збережіть (commit). За хвилину-дві GitHub Actions збере й опублікує сторінку.

Правила тексту:
- склади розставляються автоматично; якщо поділ слова не подобається, напишіть його з дефісами (`за-плу-та-не`), і скрипт його не чіпатиме;
- числа пишемо словами (`три`, не `3`);
- розділові знаки приліплюємо до слова (`скарб!`), окреме тире не ставимо;
- `{id}` після назви не міняємо в уже пройдених рівнях: за ним зберігаються зірки.

Якщо в тексті помилка, збірка зупиниться й покаже, де саме (вкладка **Actions**).

## Структура

- `levels/*.md` — тексти, один файл на розділ, порядок за номером на початку імені
- `src/template.html` — сторінка без текстів
- `src/syllables.js` — автоматичний поділ на склади
- `src/icons/` — логотип і іконки сайту (SVG і PNG для вкладки браузера та домашнього екрана)
- `build.js` — збирає `dist/index.html`, ділить на склади і перевіряє тексти (`node build.js`)
- `AGENTS.md` — правила й нюанси для тих, хто змінює проєкт (зокрема AI-асистентів)
- `.github/workflows/pages.yml` — збірка й публікація на GitHub Pages після кожного commit у `main`
