# Книжкова печера

Тренажер читання вголос українською. Читач читає текст, браузер розпізнає мовлення, прочитані слова зеленіють. 50 рівнів у 5 розділах, зірки й кубки за проходження.

Працює в браузері, без сервера і без API-ключів. Мікрофон доступний лише через `https://` або `localhost`, тому сторінка публікується на GitHub Pages.

## Як додати рівень

1. Відкрийте потрібний файл у `levels/` (можна просто в застосунку GitHub або на github.com).
2. Додайте блок:

   ```
   ## Назва рівня
   Ось но-вий текст. Скла-ди ді-ли-мо ди-фі-сом.
   ```

3. Збережіть (commit). За хвилину-дві GitHub Actions збере й опублікує сторінку.

Правила тексту:
- кожен склад має рівно одну голосну (`ко-ше-ня`, `під-ві-кон-ня`);
- числа пишемо словами (`три`, не `3`);
- розділові знаки приліплюємо до слова (`скарб!`), окреме тире не ставимо;
- `{id}` після назви не міняємо в уже пройдених рівнях: за ним зберігаються зірки.

Якщо в тексті помилка, збірка зупиниться й покаже, де саме (вкладка **Actions**).

## Структура

- `levels/*.md` — тексти, один файл на розділ, порядок за номером на початку імені
- `src/template.html` — сторінка без текстів
- `build.js` — збирає `dist/index.html` і перевіряє склади (`node build.js`)
- `.github/workflows/pages.yml` — збірка й публікація на GitHub Pages після кожного commit у `main`
