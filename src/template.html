GitHub

Про дані. Сама сторінка нічого не зберігає на сервері й нікуди не надсилає: прогрес і налаштування лежать лише у вашому браузері. Але розпізнавання мовлення виконує браузер, і зазвичай він передає звук для обробки своєму виробнику: Chrome і Samsung Internet — Google, Edge — Microsoft, Safari — Apple. Умови обробки визначає ця компанія, а не сайт. Розпізнавання вмикається лише після натискання «Читати» й дозволу на мікрофон. Шрифти завантажуються з Google Fonts, а сайт розміщено на GitHub Pages, тож ці сервіси бачать технічні дані відвідування, як-от IP-адресу.
